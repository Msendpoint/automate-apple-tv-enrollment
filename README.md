# Automate Enrollment of Apple TV Devices

> Automate the enrollment of corporate-owned Apple TV devices into Microsoft Intune using Apple's ADE.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/automate-apple-tv-enrollment.git
cd automate-apple-tv-enrollment

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```
